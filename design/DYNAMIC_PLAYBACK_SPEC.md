# 动态贴纸与壁纸播放方案

日期：2026-11-16。当前 preview.13 已接入剧场环境动效、眨眼/捧心/害羞三款真实动态欢迎贴纸、鎏金剧场动态壁纸和透明风车。欢迎均约 5 秒，播放后停 6 秒；剧场为约 9.92 秒静音往返循环，清晰红幕填充周边，不再虚化两侧。其余三张壁纸仍为静态；真实资源与独立合成视频分别有验证记录。

环境动效使用独立的 SVG/CSS 层，仅在空间足够的鎏金剧场会话区域显示。环境开关默认开启且独立保存，暂停壁纸时同步定格，恢复后沿原时间线继续；关闭装饰或环境时隐藏，后台/减少动态时暂停。它不改变人物曝光、不拦截输入、不随模型任务完成额外触发闪光。

## 已确认

- 欢迎区沿用现有三款 Q 版，每个新会话随机选择，同一会话保持选中款。
- 首批先制作眨眼小阿哈。欢迎视频播完后停几秒，再循环。
- 首张动态壁纸为鎏金剧场，人物眨眼、手势与飘带动作更明显。
- 进入正式聊天后，壁纸继续循环；用户可以随时暂停。
- 壁纸区域的小按钮和主题设置都提供播放/暂停入口。
- 同屏欢迎、风车等角色素材保持独立；金框由应用单独绘制。
- 默认无声，音乐保持独立。只提供内置资源，不开放自定义图片/视频或外部 URL。

## 建议的首轮行为

### 欢迎贴纸

新会话出现时立即播放一遍，结束后停在自然收尾姿势，按 **停留 6 秒** 再重播。6 秒是已采用的初始默认，可在实看小样后调整。

输入、切换壁纸和调整外观时，不重抽款式，也不因普通重新渲染重播。发送消息进入正式聊天后，欢迎播放器随欢迎区收起并释放。三款均有关联包内动画，关闭动效或资源失败时继续使用各自的原静态图；随机逻辑仍覆盖三款。

系统减少动态、用户关闭欢迎贴纸动效或页面进入后台时，停止播放；不自动播放声音。新会话重新登场与同一会话回到欢迎页应分别处理，避免反复触发进场效果。

### 动态壁纸

会话页默认持续循环，不随模型任务开始/结束而改变播放。暂停时定格当前帧，恢复后继续；保留播放偏好，切换壁纸不会把用户手动暂停改回播放。显影和阅读遮罩继续由用户控制，不因开始回复而自动加白或改变人物曝光。

离开可见会话区域、页面进入后台、系统减少动态或停用主题时暂停。后台返回后只恢复原本允许播放的资源，用户手动暂停仍然有效。资源不可用时使用对应静态海报，不影响聊天输入。

画面按完整人物适配，不拉伸人物；不同宽高的周边用现有舞台底色或帷幕衔接。视频模式使用视频人物，不再叠加静止的人物保护层，避免脸部与身体双影。金框和字标保持清晰、稳定。

### 小按钮与设置

小按钮采用红金细边样式，建议放在壁纸边缘、靠右上的安全位置，避开宿主工具按钮、右下风车和输入框。小窗口没有安全空间时保留主题设置入口。只在当前壁纸有动态资源且启用动态模式时显示。

按钮点击和键盘聚焦均可用，提示为“暂停壁纸”或“继续播放壁纸”。设置中的状态与按钮同步。不会新增底部信息条或音乐控制栏。

同一张壁纸下面切换静态/动态，不拆成两个重复的图库项目；收藏继续跟随原有壁纸 ID。欢迎贴纸、动态壁纸、输入与任务动效、风车各自有明确的控制范围，系统减少动态统一约束它们。

## 首批素材与制作顺序

1. 用 `animation-inputs/first-batch/01-wink-sticker-master.png` 与同名提示词，先做一条短小样，检查睁眼/wink、猫爪与头发轮廓。
2. 样片通过后接入欢迎播放器，检查透明边缘、间隔循环、切会话和暂停；继续保留三款随机。
3. 用 `02-gilded-stage-master.png` 与同名提示词制作鎏金剧场，检查脸、手、权杖、飘带、完整人物和循环接缝，再接入壁纸播放器。
4. 第一套播放流程稳定后，补齐捧心与害羞两款动态素材，最后进行 macOS 实机适配。

素材和可复制提示词已准备在 `animation-inputs/aha-jimeng-first-batch.zip`。贴纸需验证纯色抠像后才能确定透明载体；生成文件要保留原始导出质量。欢迎与整幅壁纸分别导出，不将 UI、金框或音乐烘焙到视频。

## 工程边界和验收

- 在 `wallpaper-surface.mjs` 内实现视频与静态回退；欢迎媒体独立于 `welcome.mjs` 的选款缓存，避免播放状态改变随机结果。
- 继续使用白名单资源 ID 和包内资源；扩展视频前核实 DSH 的资源加载方式，不依赖本机固定路径。只加载当前资源，切换和停用时清理播放器及计时器。
- 验证 Windows 的播放、暂停定格、恢复、静音、后台、减少动态、手动暂停持久化、首尾衔接及错误回退；macOS 另行实机确认。
- 四档窗口继续检查无横向溢出、按钮不挡原生操作、完整人物和金框贴合；保持现有任务风车与谢幕行为。
